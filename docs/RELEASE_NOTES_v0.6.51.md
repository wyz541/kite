# Kite v0.6.51

Kite v0.6.51 aligns sort indicators in detailed column headers on Windows and macOS.

## Column header layout

- Place the sort indicator after the Name title.
- Apply the same title-first order to Date, Type, and Size headers.
- Keep the active ascending or descending arrow next to its field label.
- Preserve clickable header sorting and per-directory sort rules.
