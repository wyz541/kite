# Kite v0.6.39

Kite v0.6.39 adds the column sort-direction control to macOS.

## macOS column sorting

- Add a sort-direction button to every macOS column header.
- Toggle name sorting between ascending and descending order.
- Keep folders before files in both sort directions.
- Keep the sort direction independent for each column.
- Match the Windows column sort control.
