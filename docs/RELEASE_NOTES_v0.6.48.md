# Kite v0.6.48

Kite v0.6.48 adds sorting from detailed column headers on Windows and macOS.

## Column header sorting

- Click the Name, Date, Type, or Size header to select the sort field.
- Click the active header again to switch between ascending and descending order.
- Use ascending order by default for Name and Type.
- Use descending order by default for Date and Size.
- Keep folders before files.
- Preserve sort rules for each directory.
