# Kite v0.6.35

Kite v0.6.35 improves column navigation and adds optional detailed metadata to the active macOS column.

## Column navigation

- Hold `Shift` and scroll the mouse wheel up or down to move the column strip horizontally.
- Scroll up to reveal earlier columns.
- Scroll down to reveal later columns.
- Keep touchpad horizontal scrolling and the horizontal scrollbar available.

## macOS detailed column

- Add a metadata toggle to the active column header.
- Show date, type, and size columns when metadata is visible.
- Widen the active column to keep metadata readable.
- Persist the metadata visibility preference across launches.
- Keep size values visible at the trailing edge.

## macOS toolbar

- Rebalance the leading toolbar controls against the sidebar width.
- Move the selected-item open action into the file action group.
- Keep the sidebar toggle aligned after the traffic-light area.
