# Kite v0.6.22

Kite v0.6.22 introduces the Twin Flow application icon.

## Twin Flow icon

- Use a transparent canvas.
- Use an asymmetric glass delta wing.
- Use an orange left sail.
- Use a navy right sail.
- Use two tails for parallel data flow.
- Use a navy hexagonal tail spool for engineered structure.
- Remove the old diamond frame, cross spars, center gear, and tail bows.
- Use an SVG master for every platform asset.
- Generate PNG, ICO, and ICNS from one source.
- Add the macOS application icon to the app bundle.

![Kite Twin Flow icon](https://raw.githubusercontent.com/wyz541/kite/v0.6.22/assets/kite-icon-preview.png)
