# Kite v0.6.9

Kite v0.6.9 makes preview information selectable and copyable.

## Selectable preview

- Select text in the Windows text preview.
- Select preview property values with the mouse.
- Copy the selection with `Ctrl+C`.
- Select property labels and values on macOS.
- Copy the selection with `Command+C`.
- Keep selection inside the preview pane.

## Copy all preview information

- Add a copy button to the preview header.
- Copy name, type, size, modified date, and path.
- Copy Git status when available.
- Copy SVN status when available.
- Show copy confirmation on Windows.
