# Kite v0.6.21

Kite v0.6.21 runs batch files in their own directory.

## Batch file launch

- Use Windows Shell to open files with the parent path as the working directory.
- Run `.bat` and `.cmd` files from their own folder.
- Fix relative paths inside batch scripts.
- Keep normal Shell file associations.
- Add a live ignored batch working-directory test.
- Update file launch documentation.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Live batch working-directory test.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.21-windows-x64.zip`.
- macOS: use `Kite-v0.6.21-macOS-arm64.zip`.
