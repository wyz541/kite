# Kite v0.6.15

Kite v0.6.15 keeps the first-level context menu visible with native options.

## Context menu

- Hover `显示更多选项 (Show more options)` to open the native menu.
- Keep the first-level Kite menu visible.
- Show a right chevron on the native options item.
- Prevent repeated native menu requests during one hover.
- Keep click and keyboard action fallback.
- Refresh files after the native menu closes.
- Keep column menus and list-row menus consistent.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.15-windows-x64.zip`.
- macOS: use `Kite-v0.6.15-macOS-arm64.zip`.
