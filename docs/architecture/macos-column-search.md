# macOS 分栏搜索

## 结论

macOS 每个分栏标题栏提供搜索按钮。
搜索在当前分栏目录及其子目录中执行。
搜索结果保留在触发搜索的分栏内。

## 交互

1. 点击分栏标题栏的搜索按钮。
2. 输入项目名称。
3. 按 Enter 开始搜索。
4. 按 Esc 或关闭按钮退出搜索。
5. 关闭搜索后恢复原目录列表。

同一时间只保留一个打开的搜索栏。
切换到另一分栏搜索时，Kite 关闭前一搜索栏。

## 数据流

1. SwiftUI 将目录路径和搜索词传给 Rust Core。
2. Rust Core 使用并行目录遍历读取子目录。
3. Rust Core 返回最多 1000 个匹配项目。
4. SwiftUI 将结果写入对应分栏。
5. 当前排序、筛选和分组规则应用到搜索结果。

## 取消与状态

- 新搜索取消正在运行的旧搜索。
- 关闭搜索取消正在运行的任务。
- 切换页签取消当前搜索任务。
- 搜索结果显示结果数量和截断状态。
- 崩溃或目录读取失败不会覆盖原目录列表。

## 范围

当前搜索只匹配项目名称。

## 全局工具栏搜索

工具栏提供全局搜索入口。
全局搜索在活动页签的当前目录中执行。
搜索按钮打开工具栏输入框。
菜单命令“搜索当前文件夹”使用 Command+Shift+F。
按 Enter 开始搜索。
按 Esc 或关闭按钮退出搜索。
搜索结果替换分栏区域。
结果行显示项目名称和相对目录。
双击文件夹打开该文件夹。
双击文件使用系统默认程序打开。
关闭搜索后恢复当前分栏。
切换页签或导航到其他目录会取消全局搜索。
