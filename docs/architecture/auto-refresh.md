# 分栏自动刷新

## 结论

Windows 和 macOS 的可见分栏监听文件系统变化。
创建、删除、重命名和元数据变化会自动更新分栏。
用户不需要点击刷新按钮。

## Windows

Windows 使用 `ReadDirectoryChangesW` 后端。
Kite 监听当前可见的本地目录分栏。
事件经过 180 ms 防抖后执行。
变化目录在后台重新读取。
更新保留排序、筛选、分组、选中项和滚动位置。
选中目录消失时，右侧失效分栏会关闭。
移动设备命名空间不启用目录事件监听。

## macOS

macOS 使用 `DispatchSourceFileSystemObject`。
Kite 为活动页签的可见分栏建立目录监听。
目录描述符在重命名或删除后重新建立。
事件经过防抖后执行。
目录列表在后台任务中重新读取。
更新不会清除分栏视图规则或搜索文本。

## 约束

监听只覆盖可见分栏，不递归扫描整个磁盘。
目录读取失败时保留上一次有效列表。
文件预览随选中的文件刷新。
刷新按钮继续保留，用于手动重试。
