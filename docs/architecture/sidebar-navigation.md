# Kite 侧边栏导航

## 结论

侧边栏是扁平导航入口。
侧边栏不显示可展开目录树。
点击目录后，右侧分栏显示目标目录。
收藏文件点击后打开文件。

## 数据流

1. 用户点击侧边栏项目。
2. Kite 解析目标路径。
3. 目录路径进入现有分栏导航流程。
4. 文件路径交给系统默认程序打开。
5. 当前路径和分栏选择同步更新。

## 内容

- 快速访问。
- 收藏。
- 设备。
- 此电脑。
- 底部设置入口。

## 交互

- 目录项目不显示展开箭头。
- 点击目录项目直接导航。
- 分栏模式在右侧更新分栏链。
- 列表模式在右侧更新当前目录列表。
- 收藏文件夹使用相同导航逻辑。
- 收藏文件直接打开。
- 侧边栏项目右键菜单提供“打开”和“属性”。
- 收藏项右键菜单额外提供“从收藏移除”。
- macOS 侧边栏项目右键菜单提供“显示简介”。
- Windows“此电脑”磁盘项目显示剩余空间和总空间。

## 稳定性

- 侧边栏不读取第二层目录。
- 侧边栏不缓存目录树。
- 侧边栏整体支持纵向滚动。
- 侧边栏导航复用分栏加载和错误处理。
- macOS 与 Windows 使用相同的扁平导航语义。

## 验证

- 点击快速访问目录后更新右侧分栏。
- 点击收藏文件夹后更新右侧分栏。
- 点击收藏文件后打开文件。
- 点击磁盘后显示磁盘根目录。
- 右键任意侧边栏项目可打开系统属性窗口。
- Windows 磁盘项目显示“剩余空间 / 总空间”。
- Windows GPUI 测试。
- Windows Clippy。
