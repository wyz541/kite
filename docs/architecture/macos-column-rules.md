# 分栏显示规则

## 结论

macOS 和 Windows 按目录路径保存分栏显示规则。
显示规则包括排序字段、排序方向、分组和折叠组。
筛选属于当前会话状态，不写入持久化配置。
详细信息列和列宽属于全局布局配置。
分栏搜索不属于本文范围。

## 排序

支持以下排序字段：

- 名称。
- 修改日期。
- 类型。
- 大小。

文件夹始终排在文件前。
排序方向按钮在升序和降序之间切换。
排序不触发磁盘读取。
排序字段和方向按目录路径保存。
Windows 列表视图使用同一保存的排序方向作为初始排序。

## 筛选

支持以下筛选：

- 全部项目。
- 仅文件夹。
- 仅文件。
- 媒体文件。
- 文档文件。

筛选使用文件扩展名判断媒体和文档类别。
筛选后没有项目时，分栏显示“筛选后无项目”。

## 分组

支持以下分组：

- 不分组。
- 按类型。
- 按扩展名。
- 按修改日期。

分组标题使用独立行显示。
分组标题显示组内项目数量。
点击分组标题可折叠或展开该组。
折叠组不显示组内项目。
组内项目沿用当前排序规则。
修改日期分组包括“今天”“最近 7 天”“最近 30 天”“更早”和“未知日期”。

## 重置

“重置分栏显示规则”恢复名称升序、全部项目和不分组。
重置会清除已折叠组。
重置只影响当前分栏。

## 持久化

Windows 将显示规则保存在 `Kite/ui.json`。
macOS 将显示规则保存在用户默认设置。
每个目录路径保存独立规则。
规则包括排序字段、排序方向、分组和折叠组。
没有目录专用规则时，Kite 使用最近一次修改的排序和分组规则。
新目录不会继承已折叠组。
配置最多保留 512 个目录规则。

## 详细信息列

详细信息列支持以下开关：

- 修改日期。
- 类型。
- 大小。

布局菜单提供紧凑、标准和宽列三个列宽预设。
布局菜单提供“重置列与布局”命令。
布局配置保存在 macOS 用户默认设置中。
列开关和列宽改变后，Kite 重新计算活动列宽度。

## Windows 一致性

Windows 分栏使用相同规则字段和默认行为。
Windows 列表视图保存最后使用的排序字段和方向。
Windows 和 macOS 都支持点击分组标题折叠或展开。
旧版 `ui.json` 无需迁移。
缺失字段使用默认值。
