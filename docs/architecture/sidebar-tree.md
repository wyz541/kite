# Kite 侧边栏目录树

## 结论

侧边栏目录使用按需加载的树。
点击箭头只展开或折叠目录。
首次点击目录名称或图标时，Kite 展开该目录并执行导航。
再次点击已展开目录名称时，Kite 只执行导航。

## 数据流

1. 点击目录箭头。
2. Kite 将目录加入展开集合。
3. Kite 在后台读取直接子项目。
4. Kite 缓存子项目结果。
5. Kite 递归显示已展开节点。

## 约束

- 显示直接子文件夹和直接子文件。
- 文件夹排在文件前。
- 单次展开最多读取 256 个直接子项目。
- 子项目读取失败时显示错误行。
- 空目录展开后显示“没有项目”。
- 目录箭头在空目录中保持可见。
- 设备便携项目当前不建立树。
- 展开状态只保存在当前应用会话。
- 展开缓存不写入收藏配置。

## 交互

- 点击箭头不触发目录导航。
- 点击未展开目录会展开并导航。
- 点击已展开目录只导航。
- 点击箭头只控制展开状态。
- 收藏文件点击后打开文件。
- 收藏文件夹可展开。
- 收藏项右键菜单提供“从收藏移除”。

## 稳定性

- 子项目读取在后台执行。
- 失败结果保留在树状态中。
- 侧边栏整体支持纵向滚动。
- 目录树不阻塞启动。
- 目录树不改变当前分栏加载规则。

## 验证

- 直接子目录加载测试。
- 文件与文件夹排序测试。
- Windows GPUI 测试。
- Windows Clippy。
- macOS 编译不受 Windows 树状态结构影响。
