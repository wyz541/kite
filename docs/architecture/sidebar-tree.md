# Kite 侧边栏目录树

## 结论

侧边栏目录使用按需加载的树。
点击箭头展开或折叠目录。
点击目录名称或图标执行导航。

## 数据流

1. 点击目录箭头。
2. Kite 将目录加入展开集合。
3. Kite 在后台读取直接子目录。
4. Kite 缓存子目录结果。
5. Kite 递归显示已展开节点。

## 约束

- 只显示目录，不显示普通文件。
- 单次展开最多读取 256 个直接子目录。
- 子目录读取失败时显示错误行。
- 空目录展开后隐藏箭头。
- 设备便携项目当前不建立树。
- 展开状态只保存在当前应用会话。
- 展开缓存不写入收藏配置。

## 交互

- 点击箭头不触发目录导航。
- 点击名称或图标触发目录导航。
- 收藏文件点击后打开文件。
- 收藏文件夹可展开。
- 收藏项右键菜单提供“从收藏移除”。

## 稳定性

- 子目录读取在后台执行。
- 失败结果保留在树状态中。
- 侧边栏整体支持纵向滚动。
- 目录树不阻塞启动。
- 目录树不改变当前分栏加载规则。

## 验证

- 直接子目录加载测试。
- 普通文件过滤测试。
- Windows GPUI 测试。
- Windows Clippy。
- macOS 编译不受 Windows 树状态结构影响。
