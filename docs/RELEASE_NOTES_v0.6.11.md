# Kite v0.6.11

Kite v0.6.11 fixes file preview from earlier columns.

## Earlier-column preview

- Select a file in any column.
- Remove columns below the selected file.
- Show the selected file preview.
- Show file properties for the selected file.
- Scroll the column strip to reveal the preview.
- Keep folder selection unchanged.
- Keep deeper columns when a folder remains selected.
- Keep the same behavior on macOS.
