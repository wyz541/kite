# Kite v0.6.16

Kite v0.6.16 makes the column preview larger and scrollable.

## Preview

- Increase the preview pane width to 420 pixels.
- Increase the text and image preview viewport to 440 pixels.
- Render preview text as fixed-height rows in a virtual list.
- Add an always-visible vertical scrollbar with a clear track and thumb.
- Keep text selection across visible preview rows.
- Route vertical wheel input to the preview text.
- Keep horizontal gestures on the column strip.
- Show file properties below the preview viewport.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.16-windows-x64.zip`.
- macOS: use `Kite-v0.6.16-macOS-arm64.zip`.
