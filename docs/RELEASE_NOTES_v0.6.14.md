# Kite v0.6.14

Kite v0.6.14 fixes the folder creation dialog.

## Folder creation

- Open the folder creation dialog with an empty focused input.
- Show the `文件夹名称` placeholder.
- Create the folder after Enter or the create button.
- Clear the modal input after success.
- Close the folder creation dialog after success.
- Keep the dialog open after an error.
- Apply the same close behavior to rename and VCS commit dialogs.
- Keep the macOS folder name prompt empty by default.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.14-windows-x64.zip`.
- macOS: use `Kite-v0.6.14-macOS-arm64.zip`.
