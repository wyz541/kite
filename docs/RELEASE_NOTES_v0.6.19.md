# Kite v0.6.19

Kite v0.6.19 renders Markdown inside TXT, MD, and Markdown previews.

## Markdown preview

- Render TXT files with Markdown formatting.
- Render MD and Markdown files with Markdown formatting.
- Support headings, bold text, italic text, lists, links, quotes, and code blocks.
- Keep preview text selection.
- Keep the always-visible vertical scrollbar.
- Keep vertical wheel routing inside the preview.
- Keep horizontal gestures on the column strip.
- Add the `markdown` extension to text previews.
- Add Markdown format selection tests.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.19-windows-x64.zip`.
- macOS: use `Kite-v0.6.19-macOS-arm64.zip`.
