# Kite v0.6.23

Kite v0.6.23 enlarges the Twin Flow application icon.

## Icon scale

- Increase the visible icon content to about 92% width.
- Increase the visible icon content to about 95% height.
- Recenter the artwork inside the transparent canvas.
- Improve clarity at 16 px, 24 px, and 32 px.
- Keep the orange and navy glass palette.
- Keep the twin data ribbons.
- Regenerate the PNG master.
- Regenerate the Windows ICO.
- Regenerate the macOS ICNS.

![Kite Twin Flow icon](https://raw.githubusercontent.com/wyz541/kite/v0.6.23/assets/kite-icon-preview.png)
