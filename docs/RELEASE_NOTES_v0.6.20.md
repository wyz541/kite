# Kite v0.6.20

Kite v0.6.20 adds an enlarged preview window.

## Enlarged preview

- Add a maximize button to the column preview header.
- Open the selected file in an independent GPUI window.
- Render TXT, MD, and Markdown files with Markdown formatting.
- Render plain text and code in fenced code blocks.
- Support images in the enlarged preview.
- Keep text selection in the enlarged window.
- Add an always-visible vertical scrollbar.
- Load file content asynchronously.
- Show loading state, file path, and preview errors.
- Add a safe Markdown code fence helper and test.

## Verification

- Windows Core tests.
- Windows GPUI tests.
- Windows Clippy.
- Windows release build.
- macOS Core tests.
- macOS Clippy.
- macOS SwiftUI and AppKit application build.

## Install

- Windows: use `Kite-v0.6.20-windows-x64.zip`.
- macOS: use `Kite-v0.6.20-macOS-arm64.zip`.
