# Kite 截图隐私规则

## 结论

Kite 仓库不保存本机界面截图。
截图可能包含用户名、路径、设备名、磁盘容量和最近文件。

## 禁止内容

截图不得包含以下信息：

- Windows 用户名。
- `/Users/<name>` 路径。
- `C:\Users\<name>` 路径。
- 本机磁盘容量。
- 设备名称。
- 主机名、IP 地址或序列号。
- 最近文件、搜索记录或页签名称。
- 未公开项目名称。

## 发布规则

- 仓库默认忽略 `docs/screenshots/`。
- 发布包不包含截图目录。
- 截图只用于本机验收。
- 需要公开截图时，使用合成目录。
- 公开截图前，裁掉系统标题栏、地址栏和侧边栏。
- 公开截图前，由第二人检查隐私内容。

## 自动化约束

- `*.png` 默认加入 `.gitignore`。
- `assets/kite-icon-master.png` 是唯一允许的产品图片。
- `build.ps1` 不复制截图到发布包。
